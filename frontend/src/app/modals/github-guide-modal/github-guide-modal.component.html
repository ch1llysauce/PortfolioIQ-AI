GitHub Connection Guide

To enable secure GitHub account linking and project importing, connect your GitHub App in Supabase in 2 minutes:

Step 1

Create an OAuth App on GitHub

Go to github.com/settings/developers ↗ and click New OAuth App.

Step 2

Configure URLs

• Application Name: PortfolioIQ-AI

• Homepage URL: http://localhost:4200

• Authorization callback URL:

https://rigtwkuypixwwontbckr.supabase.co/auth/v1/callback
Step 3

Enable in Supabase Dashboard

Generate a Client Secret in GitHub, then go to your Supabase Auth Providers ↗.

Enable GitHub, paste your Client ID & Client Secret, and click Save.
