Portfolio Health Score Calculation

100-Point Industry-Standard Evaluation Model
Total Formula:
Skill Coverage (35) + Project Volume (25) + Detail Quality (20) + Activity Status (20) = 100 Max
1. Skill Coverage 35 pts max

Measures breadth of active technical stack across languages, frameworks, and databases.

min(35, (Unique Skills / 10) * 35)

• 10+ verified skills award full 35/35 points.

2. Project Volume 25 pts max

Evaluates verified proof-of-work and overall software delivery experience.

min(25, (Total Projects / 5) * 25)

• 5+ active/completed projects award full 25/25 points.

3. Detail Quality 20 pts max

Rewards thorough project descriptions, architecture, and context for recruiters.

(Projects with desc >= 15 chars / Total Projects) * 20

• Requires substantive description text per project.

4. Activity & Status 20 pts max

Assesses whether projects are completed or active vs unstarted backlog ideas.

(Completed or In-Progress Projects / Total Projects) * 20

• "Completed" or "In Progress" projects receive full points.

Target Role Alignment (%)

Measures current skill match vs required benchmark skills for your selected Target Role: (Matching Skills / Required Role Skills) * 100%.
